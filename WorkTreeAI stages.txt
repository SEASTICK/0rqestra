PRODUCT

WorkTreeAI is a public, open-source desktop application for Windows PC and macOS, with an iOS
companion planned later.

Users open an existing local software project and manage a team of AI agents through an
editable visual tree.

The interface has:
- An agent tree on the left.
- Chat and live agent activity on the right.
- Node settings for role, provider, model, instructions, tools, and usage limits.

Users connect supported official provider CLI tools, initially OpenAI Codex CLI and Claude
Code CLI, through supported authentication methods. Provider documentation and subscription
conditions must be verified before implementation, not assumed.

The desktop app runs the provider CLIs and project commands locally. AI inference is handled
by the connected providers, not by WorkTreeAI itself.

AGENT BEHAVIOUR

The Manager is the user's only conversation partner.

For every prompt, the Manager:
- Interprets the request for routing.
- Delegates specialist planning and work to configured agents.
- Tracks task progress.
- Routes problems to appropriate specialists.
- Passes findings and results between agents.
- Reports outcomes and asks the user questions when necessary.

The Manager does not write code, perform specialist reviews, or solve technical problems
itself.

App-provided specialist roles include:
- Planner
- Builder
- Code Reviewer
- Debugger
- Tester
- Security Reviewer

Users can customize the tree, add multiple agents with the same role, and choose each agent's
model and instructions.

The Manager:
- Uses only configured agents.
- Follows permitted tree connections.
- Never silently creates agents or changes models.
- Runs work automatically within configured permissions.
- Asks the user when a role is missing, a decision requires input, or a retry limit is reached.
- Pauses affected tasks while independent work may continue.

Agent activity is visible, but all user-facing questions and final summaries come through the
Manager.
